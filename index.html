Standby copies of my personal website files, kept as backups in case of deployment issues.

What this repository is for

This repository holds spare copies of the files used on my main website. If a deployment on GitHub Pages stalls or fails, these copies let me redeploy the site quickly without rebuilding anything.

What this repository is not

  • It is not my live website. The live site is at the link below.
  • It is not a version history. Older versions of my site are stored in a separate archive repository.
